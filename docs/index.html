⚡ Complete 3-Step Lifecycle Demo

Terminal Walkthrough — Lock, Inspect & Unlock blockvault v2.2.0

1. Lock Any Folder or File

Computes RFC 6962 SHA-256 Merkle tree leaves, derives master keys via Scrypt (N=16384), compresses the payload, and seals the container with AES-256-GCM authenticated encryption.

2. 12 or 24-Word Mnemonic

Your decryption key is represented as a standard BIP-39 mnemonic seed phrase. Write it down on a piece of paper or password manager—no one on Earth can decrypt your data without it.

3. Zero-Knowledge Manifest

Public header allows inspecting the block height, creator wallet address, file counts, and Merkle root hashes without ever needing or exposing your private keys.

⚡ Real Live Terminal Execution

Step 1: Creating a Genesis Block Vault $ blockvault lock ~/Downloads/images --replace
Step 2: Inspecting Public Block Header & Merkle Manifest $ blockvault inspect ~/Downloads/images.block
Step 3: Unlocking & Cryptographic Merkle Verification $ blockvault unlock ~/Downloads/images.block
